# Pranav - Senior SDET Portfolio

Personal portfolio website built with React, TypeScript, Vite, and Tailwind CSS.

## Features

- ⚡️ **Vite** - Super fast build tool
- ⚛️ **React** - Component based UI
- 🔷 **TypeScript** - Type safety
- 🎨 **Tailwind CSS** - Utility-first CSS framework
- 📱 **Responsive** - Mobile friendly design
- 🚀 **GitHub Pages** - Automated deployment

## Local Development

1. Clone the repository
   ```bash
   git clone https://github.com/pranavj2009/pranav-portfolio.git
   ```

2. Install dependencies
   ```bash
   cd pranav-portfolio
   npm install
   ```

3. Start dev server
   ```bash
   npm run dev
   ```

## Deployment

This project is configured to automatically deploy to GitHub Pages when pushing to the `main` branch via GitHub Actions.
